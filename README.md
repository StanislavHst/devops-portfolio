# DevOps Portfolio — Stanislav Rotar

Вітаю! Це моє навчальне DevOps-портфоліо, у якому зберігаються лабораторні роботи, конфігурації, документація та фінальний проєкт, створені під час вивчення DevOps.

## Про мене

Мене звати **Stanislav Rotar**. Я вивчаю DevOps і практикую роботу з Git, GitHub, операційними системами, контейнерами, середовищами виконання та автоматизацією.

## Професійна мета

Моя мета — отримати системні знання й практичні навички, необхідні для роботи на позиції DevOps Engineer.

Я хочу навчитися:

- автоматизувати процеси збирання, тестування та розгортання;
- створювати відтворювану інфраструктуру;
- працювати з контейнерами та оркестрацією;
- налаштовувати CI/CD-конвеєри;
- контролювати стан систем за допомогою моніторингу;
- безпечно керувати доступом і конфігураціями;
- працювати з хмарною інфраструктурою.

## Технології, з якими я вже працюю

- **Git** — конфігурація, гілки, коміти, rebase та робота з віддаленими репозиторіями;
- **GitHub** — SSH-доступ, pull request, GitHub CLI та базове керування репозиторіями;
- **PowerShell** — виконання команд, автоматизація операцій і перевірка середовища у Windows;
- **Docker Desktop** — запуск і керування контейнерами;
- **Docker Compose v2** — опис і запуск багатоконтейнерних застосунків;
- **Node.js і npm** — робота з декількома версіями через `fnm`;
- **Python** — установлення та запуск версій через `uv`;
- **Visual Studio Code** — робота з Git, Docker, YAML і Markdown;
- **YAML** — створення та перевірка конфігурацій за схемами;
- **Markdown** — оформлення технічної документації;
- **EditorConfig** — узгодження форматування файлів між редакторами.
