# DevOps Portfolio — Stanislav Rotar

Вітаю! Я **Stanislav Rotar**, розвиваюся у напрямі DevOps і будую це портфоліо як відтворюваний журнал практичних робіт: від професійного Git workflow до CI/CD, контейнеризації, хмарної інфраструктури та observability.

## Професійна мета

Моя мета — стати DevOps Engineer, який не лише запускає інструменти, а розуміє весь шлях зміни: від коміту й автоматичних перевірок до безпечного розгортання, моніторингу та відновлення системи. Особливий фокус — Infrastructure as Code, надійні CI/CD-конвеєри та автоматизація повторюваних операцій.

## Технології

### Уже використовую

- Git, GitHub і pull request workflow;
- Windows, PowerShell і базові Linux-команди;
- Docker та Docker Compose v2;
- Node.js, Python і менеджери версій `fnm` та `uv`;
- Markdown, YAML, JSON;
- базові принципи CI/CD та роботи з хмарними сервісами.

### Планую поглибити

- Linux administration і shell scripting;
- GitHub Actions та побудову безпечних CI/CD-конвеєрів;
- Kubernetes і Helm;
- Terraform та Ansible;
- AWS/Azure, мережі та керування секретами;
- Prometheus, Grafana, централізовані логи й alerting;
- DevSecOps, supply-chain security та disaster recovery.

## План розвитку на 12 місяців

| Період | Фокус | Практичний результат |
| --- | --- | --- |
| 1–3 місяці | Git, Linux, мережі, Bash/PowerShell, Docker | Відтворюване локальне середовище та контейнеризований застосунок |
